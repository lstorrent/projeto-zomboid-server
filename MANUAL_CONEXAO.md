# 🌐 Como Conectar no Servidor

## 1. Instalar ZeroTier

- Baixe em: https://www.zerotier.com/download/
- Instale e abra

## 2. Entrar na Rede

- Botão direito no ícone do ZeroTier (bandeja do sistema) → **Join New Network**
- Cole: `b103a835d2306589`
- **Avise no grupo** — preciso autorizar você no painel

## 3. Conectar no PZ

Abra o jogo → **Jogar Online** → **Conectar**:

| Campo | Valor |
|-------|-------|
| IP | `PEDIR_PRO_ADMIN` |
| Porta | `16261` |
| Usuário | Seu nome |
| Senha | `PEDIR_PRO_ADMIN` |

## ⚠️ Problemas?

| Problema | Solução |
|----------|---------|
| Connection timed out | Ainda não foi autorizado, avisa no grupo |
| Wrong password | Pede a senha pro admin |
| Lag nos primeiros segundos | Normal, espera estabilizar |

> 💬 Dúvida? Manda no grupo!
